# План: добавление блюда, итерация 4 — много избранного
Статус: черновик — ждёт утверждения

## Зачем
Избранных блюд может быть десятки. Вкладка «Избранное» рядом с «Недавними» не масштабируется: длинный список
без порядка и без своего поиска. Недавние же всегда короткие.

## Экран приёма «Обед ▾» (сверху вниз)
1. Шапка и шторка «Что добавляем?» — без изменений.
2. **Общий поиск** `Search` «Найти блюдо или продукт»: ищет по каталогу **и** избранному; при вводе — подпись «КАТАЛОГ»,
   избранные (в т. ч. собственные блюда, которых нет в каталоге) первыми с ♥; дубли по названию схлопываются.
3. Строка-переход **«Избранное · 24 ›»** (`Cell` 1966:47361 / строка `[-My food]` с шевроном) — открывает экран избранного.
4. **«Недавние»** — заголовок секции капсом и список `[-My food] -list`, **не больше 5** последних уникальных блюд.
5. Внизу `[Food] Button_Add` ×2.

## Экран «Избранное» (новый)
- Шапка «‹ Избранное» (`header_details`), счётчик блюд.
- Свой поиск **только по избранному** `Search` «Найти в избранном».
- Список по алфавиту, **группы с заголовком-буквой** (`capsSign`), строки `[-My food] -list`.
- Справа **буквенный указатель** (только если блюд > 15) — тап по букве прокручивает к группе. Не из DS.
- Пусто → `food.favorites.empty` «Здесь появятся ваши блюда». Ничего не найдено → «В избранном нет…».
- Касание → карточка блюда → добавить в выбранный приём → возврат к приёму.

## Критерии готовности
- [ ] Общий поиск находит блюда каталога и избранного, избранные первыми с ♥, без дублей.
- [ ] Недавние — не больше 5.
- [ ] «Избранное · N ›» открывает экран с алфавитными группами и поиском только по избранному.
- [ ] Указатель букв работает при > 15 блюдах; пустое и «ничего не найдено» — есть.
- [ ] Добавление из избранного попадает в выбранный приём; /look без P0/P1.

## Вне рамок
