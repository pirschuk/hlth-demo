# План: добавление блюда
Статус: черновик — ждёт утверждения

## Зачем
Пользователь записывает **одно блюдо** в нужный приём пищи быстро и не задумываясь: выбрал приём, выбрал блюдо —
готово. Целый приём пищи этим экраном не добавляется (для этого — «Повторить» на странице приёма).

## Сценарий
1. Открыть добавление: «+» на странице приёма (тип уже выбран) или общий «+» в дневнике.
2. Проверить или сменить тип приёма — **одно касание** по чипу.
3. Выбрать блюдо одним из способов:
   - **из избранного** — вкладка «Избранное»;
   - **поиском по каталогу** — избранные в результатах первыми и с ♥;
   - **по фото** — снять тарелку или загрузить из галереи (один вход);
   - **вручную** — название, КБЖУ, количество.
4. Блюдо записано → возврат к приёму, тост «Добавлено в <приём>: <блюдо>».

Касаний до результата: избранное/недавнее — **2** (вкладка, плитка), поиск — **3** (поле, ввод, плитка),
фото — **4** (кнопка, затвор, «Использовать», «Отлично»).

## Экран (сверху вниз), 393×852
**«Добавить блюдо»** — основа: тест «Плитки» на компонентах DS.
1. **Шапка** `[Food] Header`: «×» слева, заголовок по центру.
2. **Тип приёма** — 4 чипа «Завтрак / Обед / Ужин / Перекус» в одну строку, выбранный — синяя обводка.
3. **Поиск** `Search` «Найти блюдо или продукт». При вводе подборки скрываются, ниже — результаты из каталога
   и избранного (избранные первыми, с ♥).
4. **Подборки** `SegmentedControl`: «Избранное · N» / «Недавние».
5. **Плитки блюд** `[-Meal Card]` в 2 колонки: название, «ккал · г». Избранное — иллюстрированный фон и ♥.
   Касание — блюдо добавлено.
6. **Внизу, в зоне большого пальца** `[Food] Button_Add` ×2: «Добавить вручную», «Распознать по фото».
   Скрыт, пока открыта клавиатура.

Первый экран без скролла: шапка, тип, поиск, подборки, 2 ряда плиток, нижние кнопки. Главное действие — плитка блюда.

**Камера** (из «Распознать по фото»): видоискатель, затвор по центру, слева — миниатюра галереи (загрузить фото),
«×» сверху. Дальше — существующий флоу Figma: «Переснять / Использовать» → «Идёт распознавание еды» → строка в приёме.

**Ручной ввод** (из «Добавить вручную»): существующая карточка блюда в режиме ручного ввода по Figma
(«Введите, что вы ели», пищевая ценность 100 г / Порция, съеденное количество, `Summary + Button`).
Тип приёма берётся с экрана добавления и меняется в шапке карточки.

## Состояния
- default — подборка «Избранное» или «Недавние»;
- поиск с результатами;
- ничего не найдено — иллюстрация `image.food.not_found` и «Добавить вручную»;
- пустое избранное / пустые недавние — иллюстрация `food.favorites.empty` и пояснение;
- loading — скелетон плиток;
- error каталога — системное сообщение и «Обновить»;
- подтверждение касания — плитка на мгновение с галочкой, затем возврат;
- ошибка распознавания фото — существующая строка «Не удалось распознать еду» → ручной ввод.

## Данные
- Каталог блюд: `state.products` (название, ккал/Б/Ж/У на 100 г, порция) — в прототипе 8 позиций; для поиска мало.
- Избранное: `state.favorites` + `own`. Недавние: из `state.entries` (последние уникальные блюда).
- Порция по умолчанию: прошлая порция блюда, для нового — `portion` продукта или 100 г.
- Тип приёма: сейчас угадывается по времени (`mfGuessType`) — **убрать** (от времени ничего не зависит).
  Нужно поле «последний выбранный тип» — его в сторе нет.
- Фото блюд для фото-варианта `[-Meal Card]` — нет.

## Решения владельца
- Добавляем одно блюдо, не приём; без «Как вчера?».
- Избранное — вкладкой и в результатах поиска.
- Фото: снять или загрузить — один вход.
- Тип приёма — быстро, 4 варианта; от времени пока ничего не зависит.
- Ручной ввод — полностью руками.

## Критерии готовности (проверяемые на скриншоте)
- [ ] Тип приёма виден без скролла и меняется одним касанием; предвыбор не зависит от времени.
- [ ] Поиск находит блюда каталога и избранного, избранные первыми и с ♥.
- [ ] Вкладка «Избранное» показывает только избранные; поиск на ней — только по избранному.
- [ ] Касание плитки добавляет блюдо в выбранный приём и возвращает к приёму с тостом.
- [ ] «Распознать по фото» открывает камеру с загрузкой из галереи; флоу доходит до строки в приёме.
- [ ] «Добавить вручную» открывает ручной ввод с тем же типом приёма; добавление работает.
- [ ] Пустые и ошибочные состояния не прыгают по геометрии; ошибок консоли нет.
- [ ] Отклонённые тестовые варианты удалены из кода и панели.

## Вне рамок
Добавление целого приёма, изменение порции на этом экране (правится в карточке блюда), время приёма на этом экране
(есть в карточке блюда), штрихкод, голос, распознавание по текстовому описанию, «Как вчера?».
