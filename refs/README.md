# Референсы

- `mobbin/` — превью экранов из Mobbin MCP (низкое разрешение, ~299 px по ширине ≈ 393 pt) и скриншоты владельца.
  Имя: `<зона>-<app>-<экран>.jpg`. Зоны: **1** дневник / приёмы пищи, **2** страница приёма,
  **3** добавление еды, **4** общие паттерны вне ниши. Разбор — `mobbin/ANALYSIS.md`.
- Правила из референсов — в `.claude/skills/design-system/SKILL.md` (раздел «Паттерны из референсов») со ссылкой на файл отсюда.
- Новый референс: положить файл сюда и выполнить `/ref refs/mobbin/<файл>`.
