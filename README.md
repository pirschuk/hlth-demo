# Худеем на здоровье · iOS Studio (демо)

Интерактивный веб-прототип iOS-приложения. Публикуется как статический сайт (GitHub Pages): `index.html` + `assets/`.

## Исходники и сборка

Исходного проекта нет: `src/app.js` и `src/app.css` восстановлены форматированием из собранного бандла, правки вносятся в них.
Новые фичи лежат отдельными модулями в `src/modules/` (`*.js` вставляются перед `render()`, `*.css` — в конец стилей).

```bash
npm install
npm run build   # пересобирает assets/index-<hash>.{js,css} и обновляет index.html
```

Проверить локально: `python3 -m http.server` в корне и открыть http://localhost:8000.

## Модули

- `src/modules/meal-flow.*` — флоу «Добавление приёма пищи» по Figma (страница «↪ Добавление приёма пищи [new]»):
  карточка блюда (поиск / «Мои блюда» / ручной ввод / просмотр записи), шторка типа и времени приёма (HAR-710),
  камера → предпросмотр → «Идёт распознавание еды». Дизайн-система — `DESIGN_SYSTEM.md`.
