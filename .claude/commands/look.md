Экран: $ARGUMENTS (если пусто — «Питание»)

1. Проверь сборку и сервер: `npm run build`, затем
   `curl -s -o /dev/null -w "%{http_code}" http://localhost:8765/`. Не 200 →
   `python3 -m http.server 8765` в фоне и дождись 200.
2. Сними скриншоты: `node scripts/screenshot.mjs "<экран>" look` и, если экран длинный,
   с `--scroll 400` / `--scroll 800`. Для вариантов — `--set "<переключатель>=<значение>"`.
3. Открой каждый `.png` через `Read`. Пройди чек-лист раздела «Чек-лист» скилла `design-system`.
   Выпиши найденное (P0/P1/P2) с конкретными правками.
4. Исправь P0 и P1 в модуле (только компонентами и токенами DS), пересобери.
5. Пересними и снова открой. Повторяй, пока P0/P1 не останется (не больше 3 итераций — дальше
   спроси пользователя).
6. Ответ: что было не так → что исправлено, скриншоты «до/после», оставшиеся P2.
